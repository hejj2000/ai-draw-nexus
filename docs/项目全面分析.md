# AI Draw Nexus 项目全面分析

## 一、项目是什么？（一句话概括）

**AI Draw Nexus** 是一个 **AI 驱动的图表创作平台**。用户用自然语言描述想要的图表（比如"画一个用户登录流程图"），AI 就会自动生成对应的可视化图表。

在线地址：https://ai-draw-nexus.aizhi.site

---

## 二、项目能做什么？（核心功能）

### 1. 三大绘图引擎
项目支持三种不同的图表绘制方式，满足不同场景：

| 引擎 | 特点 | 适合场景 |
|------|------|----------|
| **Mermaid** | 代码驱动，用文本语法定义图表 | 流程图、时序图、类图等结构化图表 |
| **Excalidraw** | 手绘风格，简洁美观 | 头脑风暴、草图、非正式图表 |
| **Draw.io** | 专业图表编辑器，功能最丰富 | 复杂架构图、网络拓扑图等专业场景 |

### 2. 多模态输入（不止文字）
- **文字描述**：直接说"画一个电商下单流程"
- **文档可视化**：上传 Word/PDF 文档，AI 自动提取内容生成图表
- **图片复刻**：上传图片，AI 识别并复刻成可编辑图表
- **链接解析**：输入网页链接，自动抓取内容生成图表

### 3. 项目管理
- 创建/删除/重命名图表项目
- 完整的**版本历史**记录，随时回退到任意版本
- 所有数据**存储在本地浏览器**，保护隐私

### 4. AI 对话式编辑
在编辑器右侧有聊天面板，可以：
- 从零创建新图表
- 基于现有图表修改："把支付节点改成红色"
- 添加元素："增加一个库存检查步骤"

## 四、主要技术依赖详解（前端新手友好版）

### 1. React 19 + React DOM
**是什么**：最流行的前端 UI 库，用来构建用户界面  
**本项目作用**：整个应用的所有页面和组件都用 React 编写  
**新手理解**：React 让你用"组件"的方式搭积木一样构建网页

### 2. Vite
**是什么**：下一代前端构建工具，替代传统的 Webpack  
**本项目作用**：开发时提供热更新、打包生产代码  
**新手理解**：Vite 是项目的"发动机"，负责把代码转换成浏览器能运行的格式

### 3. TypeScript
**是什么**：JavaScript 的超集，增加了类型检查  
**本项目作用**：所有代码文件都是 `.ts` 或 `.tsx` 结尾  
**新手理解**：TypeScript 在写代码时就帮你检查错误，减少运行时 bug

### 4. Tailwind CSS
**是什么**：实用优先的 CSS 框架  
**本项目作用**：快速编写样式，比如 `className="flex items-center gap-2"`  
**新手理解**：不用写传统 CSS 文件，直接在 HTML 类名里写样式

### 5. React Router DOM v7
**是什么**：React 的官方路由库  
**本项目作用**：管理页面跳转，定义了 5 个路由：
- `/` 首页
- `/projects` 项目列表
- `/editor/:projectId` 编辑器
- `/profile` 个人中心
- `/about` 关于页面

### 6. Zustand
**是什么**：轻量级状态管理库  
**本项目作用**：管理应用的全局状态，定义了 3 个 Store：
- `editorStore`：当前项目、画布内容、未保存标记
- `chatStore`：聊天消息
- `payloadStore`：AI 对话的消息载荷

**新手理解**：当多个组件需要共享数据时，用 Zustand 创建一个"仓库"来存数据

### 7. Dexie.js
**是什么**：IndexedDB 的封装库，浏览器本地数据库  
**本项目作用**：把项目数据和版本历史存在用户浏览器里  
**新手理解**：即使关闭网页，数据也不会丢失，存在浏览器"硬盘"里

数据库结构：
```typescript
projects          // 项目表：id, title, engineType, thumbnail, createdAt, updatedAt
versionHistory    // 版本历史表：id, projectId, content, changeSummary, timestamp
```

### 8. 三大绘图引擎库

#### Mermaid (`mermaid`)
- 文本转图表的库
- 支持流程图、时序图、类图、甘特图等
- 本项目还注册了 ELK 和 Tidy Tree 布局引擎优化布局

#### Excalidraw (`@excalidraw/excalidraw`)
- 手绘风格的白板绘图工具
- 提供完整的画布交互（拖拽、绘制、选择等）
- AI 生成的是 JSON 数据，直接渲染成图形

#### Draw.io (`react-drawio`)
- 嵌入 diagrams.net 的专业图表编辑器
- 通过 iframe 嵌入，数据格式是 XML
- 功能最强大，适合复杂图表

### 9. AI 相关依赖

#### Radix UI 系列 (`@radix-ui/*`)
- 无障碍 UI 组件原语
- 本项目用了 Dialog（弹窗）、Dropdown（下拉菜单）、Toast（提示）、Tooltip（提示框）
- **新手理解**：这些是"半成品"组件，提供交互逻辑，样式自己定义

#### Lucide React (`lucide-react`)
- 图标库
- 项目中所有图标都来自这里

### 10. 文档处理依赖

| 依赖 | 作用 |
|------|------|
| `@mozilla/readability` | 提取网页正文内容（类似浏览器阅读模式） |
| `turndown` | HTML 转 Markdown |
| `linkedom` | 在浏览器/Node 环境中模拟 DOM |
| `mammoth` | Word 文档 (.docx) 转 HTML |

### 11. 后端相关

#### Wrangler (`wrangler`)
- Cloudflare 的开发/部署工具
- 本项目后端是 **Cloudflare Pages Functions**（Serverless 函数）
- 用 Wrangler 在本地模拟 Cloudflare 环境开发

## 六、核心工作流程

### 1. 用户创建图表的流程

```
用户输入描述 ──► 前端构建提示词 ──► 调用 /api/chat ──► AI 生成代码
                                                        │
                                                        ▼
用户看到图表 ◄── 渲染引擎解析 ◄── 提取代码并验证 ◄── 流式返回内容
    │
    ▼
自动保存到 IndexedDB（项目 + 版本历史）
```

### 2. AI 提示词系统

项目为每种引擎准备了专门的系统提示词，告诉 AI：
- 应该输出什么格式（Mermaid 语法 / Excalidraw JSON / Draw.io XML）
- 样式规范（颜色、布局等）
- 如何响应用户的编辑请求

### 3. 版本管理

每次保存时：
1. 保存当前内容到 `versionHistory` 表
2. 生成缩略图更新项目预览
3. 用户可以在"历史记录"中查看和恢复任意版本

## 七、部署方式

本项目采用 **Cloudflare Pages** 部署：
- 前端静态文件托管在 Cloudflare CDN
- 后端 API 是 Cloudflare Pages Functions（边缘计算）
- 一体化部署，无需单独服务器

## 八、给前端新手的总结

如果你是前端新手，通过这个项目你可以学习到：

1. **React 实战**：组件化开发、Hooks 使用、状态管理
2. **TypeScript**：类型定义、接口使用
3. **现代前端工具链**：Vite + pnpm + ESLint
4. **本地存储**：IndexedDB / Dexie.js 的使用
5. **AI 应用开发**：如何接入大模型 API、流式响应处理
6. **多模态输入**：文件上传、图片处理、网页解析
7. **第三方库集成**：如何把 Mermaid、Excalidraw 等库嵌入自己的应用
8. **Serverless 后端**：Cloudflare Functions 的无服务器开发

这是一个**功能完整、架构清晰**的现代化前端项目，非常适合学习全栈 AI 应用的开发模式！
