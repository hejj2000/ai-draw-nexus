## 二、移除/隐藏方案

### 方案 A：彻底移除（推荐用于完全私有化部署）

#### 步骤 1：修改 About 页面

编辑 `src/pages/AboutPage.tsx`：

**删除内容**：
- 整个"赞助支持"板块（L32-46）
- 整个"联系作者"板块（L48-60）
- 开源信息中的具体 GitHub 链接，改为纯文本或移除

**修改后保留内容建议**：
- 保留"开源项目"板块，但移除具体作者链接
- 或改为通用的 MIT 协议声明

#### 步骤 2：修改 Profile 页面

编辑 `src/pages/ProfilePage.tsx`：

**删除内容**：
- 赞赏引导链接（L228-236）

```tsx
// 删除以下代码块：
<Link
  to="/about"
  className="inline-flex items-center gap-1 text-xs text-primary hover:underline"
>
  <MessageCircle className="h-3 w-3" />
  <span>赞赏作者，进群可获得访问密码</span>
</Link>
```

#### 步骤 3：删除静态资源

```bash
# 删除赞赏和联系二维码图片
rm public/donate.png
rm public/contact.png
```

#### 步骤 4：修改 README（可选）

如需私有化，建议：
- 移除或替换在线演示地址
- 移除 GitHub 仓库链接
- 替换为自己的仓库地址

## 五、注意事项

1. **访问密码机制**：移除赞赏引导后，访问密码功能仍然可用，只是用户不知道如何获取密码。如需保留此功能，需要提供其他密码分发渠道。

2. **配额系统**：配额限制逻辑在 `src/services/quotaService.ts` 中，与作者标识无关，可独立配置。

3. **LLM 配置**：自定义 LLM 配置功能不受影响，用户仍可自行配置 API Key 使用。

4. **开源协议**：项目使用 MIT 协议，允许自由修改和私有化部署，但建议保留协议声明。
