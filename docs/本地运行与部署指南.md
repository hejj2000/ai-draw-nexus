# 本地运行与部署指南

本文档提供 AI Draw Nexus 项目的本地开发环境搭建和线上部署完整指导。

---

## 一、本地运行

### 1.1 环境准备

| 工具 | 版本要求 | 用途 |
|------|---------|------|
| Node.js | 18.x 或更高 | JavaScript 运行时 |
| pnpm | 8.x 或更高 | 包管理器（项目使用 pnpm） |
| Git | 任意版本 | 代码版本控制 |

**安装 pnpm**（如果还没有）：
```bash
npm install -g pnpm
```

### 1.2 克隆项目并安装依赖

```bash
# 克隆项目（使用你自己的仓库地址）
git clone https://github.com/liujuntao123/smart-ai-draw.git
cd smart-ai-draw

# 安装依赖
pnpm install
```

### 1.3 配置环境变量

在项目根目录创建 `.dev.vars` 文件：

```env
AI_API_KEY=sk-xxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxx
AI_BASE_URL=https://api.openai.com/v1
AI_PROVIDER=openai
AI_MODEL_ID=gpt-4o-mini
```

**配置说明**：

| 变量名 | 必填 | 说明 |
|-------|------|------|
| `AI_API_KEY` | ✅ | 你的 AI API 密钥 |
| `AI_BASE_URL` | ✅ | API 基础地址 |
| `AI_PROVIDER` | ✅ | `openai` 或 `anthropic` |
| `AI_MODEL_ID` | ✅ | 模型 ID，如 `gpt-4o-mini`、`claude-sonnet-4-5` |

**支持的 AI 服务**：

| 服务商 | AI_PROVIDER | AI_BASE_URL | 推荐模型 |
|--------|-------------|-------------|----------|
| OpenAI | `openai` | `https://api.openai.com/v1` | `gpt-5` |
| Anthropic | `anthropic` | `https://api.anthropic.com/v1` | `claude-sonnet-4-5` |
| 其他兼容服务 | `openai` | 自定义 URL | - |

> ⚠️ **费用提醒**：AI API 调用是**按量计费**的！每次生成图表都会消耗 Token，费用由你的 API Key 所属账户承担。请在对应平台查看定价详情。

### 1.4 启动开发服务器

```bash
# 同时启动前端和后端（推荐）
pnpm run dev

# 访问 http://localhost:8787
```

或者分别启动：

```bash
# 仅前端（Vite）
pnpm run dev:frontend
# 访问 http://localhost:5173

# 仅后端（Wrangler Pages Functions）
pnpm run dev:backend
# 访问 http://localhost:8787
```

> **注意**：开发时请访问 `http://localhost:8787`（wrangler 代理 vite），这样才能同时使用前端和后端 API。

### 1.5 验证运行

打开浏览器访问 `http://localhost:8787`，你应该能看到：
- 首页正常加载
- 可以创建项目
- AI 聊天功能可用（如果 API Key 配置正确）

## 二、基于 Cloudflare Pages 部署

### 2.1 部署架构

```
┌─────────────────────────────────────┐
│         Cloudflare Pages            │
│  ┌─────────────┐ ┌───────────────┐  │
│  │  前端静态页  │ │  Pages        │  │
│  │  (React)    │ │  Functions    │  │
│  └─────────────┘ └───────────────┘  │
│           │              │          │
│           └──────────────┘          │
│                   │                 │
└───────────────────┼─────────────────┘
                    │
                    ▼
┌─────────────────────────────────────┐
│         AI 服务提供商                │
│    (OpenAI / Anthropic / 其他)       │
└─────────────────────────────────────┘
```

### 2.2 前置条件

1. **Cloudflare 账号**（免费注册）
2. **GitHub 账号**（用于代码托管和自动部署）
3. **AI API Key**（OpenAI 或 Anthropic）

> ⚠️ **费用提醒**：
> - **Cloudflare Pages**：**免费**！包含无限请求、无限带宽（合理使用范围内）
> - **Cloudflare Workers**：**免费**！每天有 10 万次请求额度
> - **AI API 调用**：**按量付费**！这是唯一的费用来源，由你的 OpenAI/Anthropic 账户计费

### 2.3 部署步骤

#### 步骤 1：将代码推送到 GitHub

```bash
# 在 GitHub 创建新仓库，然后：
git remote add origin https://github.com/你的用户名/你的仓库名.git
git branch -M main
git push -u origin main
```

#### 步骤 2：连接 Cloudflare Pages

1. 登录 [Cloudflare Dashboard](https://dash.cloudflare.com)
2. 进入 **Workers & Pages** → **Create application** → **Pages** → **Connect to Git**
3. 选择你的 GitHub 仓库
4. 配置构建设置：
   - **Framework preset**：`Vite`
   - **Build command**：`pnpm run build`
   - **Build output directory**：`dist`
5. 点击 **Save and Deploy**

#### 步骤 3：配置环境变量（Secrets）

部署完成后，进入项目 → **Settings** → **Variables and Secrets** → **Add**：

| 名称 | 值 | 类型 |
|------|-----|------|
| `AI_API_KEY` | 你的 API 密钥 | Secret |
| `AI_BASE_URL` | `https://api.openai.com/v1` | Plain text |
| `AI_PROVIDER` | `openai` | Plain text |
| `AI_MODEL_ID` | `gpt-4o-mini` | Plain text |

> **Secret 类型**：`AI_API_KEY` 务必选择 **Secret** 类型，这样不会暴露在日志中。

#### 步骤 4：重新部署

添加环境变量后，Cloudflare 会自动重新部署。等待约 1-2 分钟即可访问。

#### 步骤 5：访问你的站点

部署完成后，你会获得一个 `https://你的项目名.pages.dev` 的地址。

### 2.4 自定义域名（可选）

1. 进入 Pages 项目 → **Custom domains**
2. 点击 **Set up a custom domain**
3. 输入你的域名（如 `draw.yourdomain.com`）
4. 按提示添加 DNS 记录
5. 等待 SSL 证书自动签发（通常几分钟）

> ⚠️ **费用提醒**：自定义域名使用 Cloudflare 的 DNS 和 SSL 是**完全免费**的。

## 三、费用总览

| 项目 | 费用 | 说明 |
|------|------|------|
| Cloudflare Pages | **免费** | 无限请求、无限带宽（合理使用） |
| Cloudflare Workers | **免费** | 每天 10 万次请求额度 |
| 自定义域名 | **免费** | 使用 Cloudflare DNS |
| AI API 调用 | **按量付费** | 唯一费用来源，每次生成消耗 Token |
| GitHub 仓库 | **免费** | 公开仓库免费 |

### AI 调用费用估算

以 OpenAI `gpt-4o-mini` 为例：

| 使用场景 | 单次消耗 | 100 次/月费用 |
|---------|---------|--------------|
| 简单流程图 | ~5K tokens | ~$0.15 |
| 复杂架构图 | ~15K tokens | ~$0.45 |
| 文档可视化 | ~30K tokens | ~$0.90 |

> 💡 **省钱建议**：
> 1. 设置 `VITE_DAILY_QUOTA` 限制每日使用次数（默认 10 次）
> 2. 使用 `gpt-4o-mini` 而非 `gpt-4o`，价格便宜约 20 倍
> 3. 鼓励用户配置自己的 LLM（Profile 页面支持自定义 API Key）

## 四、部署后配置

### 4.1 访问密码（可选）

如果你想控制访问权限：

1. 在 Cloudflare Pages 环境变量中添加：
   - `ACCESS_PASSWORD` = 你的密码

2. 用户访问时输入密码即可无限使用（不消耗配额）

### 4.2 每日配额设置

在 `.env` 或 Cloudflare 环境变量中设置：

```env
VITE_DAILY_QUOTA=10
```

未设置访问密码的用户，每日最多使用 10 次。

### 4.3 监控用量

- **Cloudflare**：Dashboard → Analytics 查看请求量
- **OpenAI**：Platform → Usage 查看 Token 消耗和费用
- **Anthropic**：Console → Usage 查看用量

## 五、常见问题

### Q1: 本地运行报错 `AI_API_KEY is required`
A: 检查 `.dev.vars` 文件是否正确创建，且变量名无误。

### Q2: 部署后 AI 功能不可用
A: 检查 Cloudflare Pages 的 Secrets 是否配置正确，特别是 `AI_API_KEY` 的类型是否为 Secret。

### Q3: 如何更新部署
A: 直接 `git push` 到 GitHub，Cloudflare 会自动重新构建和部署。

### Q4: 可以部署到 Vercel/Netlify 吗
A: 可以部署前端，但后端 API（Cloudflare Functions）需要重写为 Vercel Functions 或 Netlify Functions。

### Q5: 如何完全私有化（不依赖 Cloudflare）
A: 需要：
1. 前端：任何静态托管（Nginx、Vercel、Netlify 等）
2. 后端：将 `functions/api/` 改写为 Node.js/Express 服务
3. AI API：用户自行配置或使用你自己的 Key
